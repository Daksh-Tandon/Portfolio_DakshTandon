# 🌐 Portfolio Website

A modern, responsive, and dynamic developer portfolio built using **React**, **Node.js**, and **Express.js**. The portfolio is designed to showcase my skills, experience, and GitHub activity while automatically displaying my latest repositories using the GitHub API.

## 🚀 Live Demo

🔗 **Portfolio:**
https://portfoliodakshtandon-889ky486l-daksh-s-projects-5eddb8d1.vercel.app/

---

## 📌 About

This portfolio represents my journey as a Computer Science student and aspiring Software Engineer. Instead of manually updating project cards, it fetches my latest repositories directly from GitHub using the GitHub API, ensuring that visitors always see my most recent work.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Daksh-Tandon/Portfolio_DakshTandon.git
```

Move into the project

```bash
cd Portfolio_DakshTandon
```

Install dependencies

```bash
# Frontend
cd frontend
npm install

# Backend
cd ../backend
npm install
```

Run the application

```bash
# Backend
npm start

# Frontend
npm run dev
```

---

## 🔄 GitHub API Integration

The portfolio dynamically fetches repositories from GitHub using the GitHub REST API. This eliminates the need to manually update projects whenever a new repository is created.
